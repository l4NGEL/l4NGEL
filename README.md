### Merhaba

Bilgisayar mühendisliği mezunuyum; **Papilon**'da yazılım geliştiricisiyim.  
Mobil, web ve görev-kritik HMI ürünlerini uçtan uca çıkarıyorum — yüz tanıma istemcisinden kokpit ekranına, offline-first senkrondan güvenlik tarayıcısına.

Kısa İngilizce özet: *I build mobile, web, and mission-style HMI products — cockpit displays, offline-sync ledgers, and security scanners.*

**Şu an ilgilendiğim konular**
- Flutter / React Native ile üretim kalitesinde mobil deneyim
- Gerçek zamanlı telemetri, harita ve operatör panelleri
- Offline-first mimari, çakışma çözümü, senkron kuyrukları
- Kendi sistemini tarayan, kanıt üreten güvenlik doğrulama araçları
